項目 / 演算子 具体例と実行結果 (ベース: l = [10, 20, 30]) 概要・用途
[] (リスト定義) l = [10, 20, 30] カギ括弧を使って複数のデータをまとめて定義・管理する。
len() len(l) → 3 リストの要素数を取得する。
インデキシング l[0] → 10 指定した位置の要素を参照・取得する（先頭は0番目）。
スライシング l[0:2] → [10, 20] [開始位置 : 終了位置 : 飛び幅] を指定し、要素を切り出して部分リストを取得する。
l[::2] → [10, 30]
append l.append(40) → l = [10, 20, 30, 40] リストの末尾に新しい要素を追加する（破壊的変更）。
insert l.insert(1, 15) → l = [10, 15, 20, 30] 指定したインデックスの位置に要素を挿入する。
remove l.remove(20) → l = [10, 30] 指定した値に一致する最初の要素を削除する。
+ 演算子 m = l + [40, 50] → m = [10, 20, 30, 40, 50] 2つのリストを連結して新しいリストを作る（元のリストは変化しない）。
extend l.extend([40, 50]) → l = [10, 20, 30, 40, 50] 別のリストなどの要素を追加して、既存のリスト自体を拡張する。
in 20 in l → True 指定した値がリスト内に含まれているかを真偽値で返す。
